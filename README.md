# Zero-Touch Automated Ancient History Cartoon Bot (YouTube Shorts)

A 100% free, zero-human-input automated pipeline that runs every 12 hours via GitHub Actions. Each run:
1. Researches a unique global ancient history event via **Google Gemini (`google-genai` SDK, `gemini-2.5-flash`)** with strict JSON schema output and topic deduplication (`used_topics.json`).
2. Generates consistent **2D western cartoon illustrations** (`1080x1920`) using **Pollinations.ai (`flux` model)** with exponential backoff retries.
3. Synthesizes a punchy neural voiceover (`en-US-ChristopherNeural` at `+5%` speed) and synchronized subtitle timings using **`edge-tts`**.
4. Renders a vertical `1080x1920` (`30fps`) **2.5D Ken Burns (`zoompan`) animated video** with burned-in kinetic subtitles and ducked background music (`12%` volume) using pure **FFmpeg** subprocesses.
5. Automatically publishes the rendered video to **YouTube Shorts** via the **YouTube Data API v3** and commits the completed topic back to `used_topics.json`.

## Step-by-Step Setup Instructions

### 1. Prerequisites (Local Development)
- **Python 3.11+**
- **FFmpeg** (with `libx264`, `libass`, and `ffprobe` on your system `PATH`)

Install Python dependencies:
```bash
pip install -r requirements.txt
```

### 2. Get Your Free Gemini API Key
1. Go to [Google AI Studio](https://aistudio.google.com/apikey).
2. Click **Create API Key** and copy the key (`GEMINI_API_KEY`).

### 3. Set Up YouTube Data API v3 & Generate `YOUTUBE_REFRESH_TOKEN`
1. Go to the [Google Cloud Console](https://console.cloud.google.com/).
2. Create a project and enable the **YouTube Data API v3** under **APIs & Services > Library**.
3. Go to **APIs & Services > OAuth consent screen**:
   - Choose **External**, fill in the required app name and email fields.
   - Add the scope `https://www.googleapis.com/auth/youtube.upload`.
   - Under **Test users**, add your YouTube channel's Google account email.
4. Go to **APIs & Services > Credentials**:
   - Click **Create Credentials > OAuth client ID**.
   - Select **Desktop app** (or **Web application** with `http://localhost:8080/` in Authorized redirect URIs).
   - Copy your **Client ID** (`YOUTUBE_CLIENT_ID`) and **Client Secret** (`YOUTUBE_CLIENT_SECRET`).
5. Run the one-time OAuth helper script locally to obtain your `YOUTUBE_REFRESH_TOKEN`:
   ```bash
   python setup_youtube_oauth.py --client-id "YOUR_CLIENT_ID" --client-secret "YOUR_CLIENT_SECRET"
   ```
   A browser window will open. Sign in with your YouTube account, grant upload permission, and copy the printed `YOUTUBE_REFRESH_TOKEN`.

### 4. Configure GitHub Actions Secrets
In your GitHub repository, navigate to **Settings > Secrets and variables > Actions > New repository secret** and add these 4 secrets:

| Secret Name | Description |
| :--- | :--- |
| `GEMINI_API_KEY` | Your Google AI Studio Gemini API key |
| `YOUTUBE_CLIENT_ID` | Your Google Cloud OAuth 2.0 Client ID |
| `YOUTUBE_CLIENT_SECRET` | Your Google Cloud OAuth 2.0 Client Secret |
| `YOUTUBE_REFRESH_TOKEN` | Refresh token generated by `setup_youtube_oauth.py` |

Also ensure **Settings > Actions > General > Workflow permissions** is set to **Read and write permissions** so the workflow can commit updates to `used_topics.json`.

## Local Verification & Testing

### Dry Run (Render Full Video Without Uploading)
```bash
# With GEMINI_API_KEY set in environment or .env:
python bot.py --dry-run

# Or using the built-in 5-scene Ancient Rome sample script (--mock-llm):
python bot.py --dry-run --mock-llm
```

The rendered short is saved to `output/final_short.mp4`.

### Inspect Rendered Output with `ffprobe`
```bash
ffprobe -v error -show_entries format=duration -show_entries stream=codec_name,width,height,r_frame_rate -of default=noprint_wrappers=1 output/final_short.mp4
```
